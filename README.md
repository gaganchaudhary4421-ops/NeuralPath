# NeuralPath 🧠

### AI-Powered Personalized Learning Path Generator

> ATH Hackathon 0.1 – 2026 | Problem Statement: PS-02

---

---

## What it Does

NeuralPath takes your goal (e.g. "Learn Web Development")
and generates a complete personalized roadmap with:

- Step by step topics to learn
- Curated resources for each topic
- Progress tracking
- Skill gap detection

---

## Tech Stack

- **Frontend:** React + Vite
- **Backend:** FastAPI (Python)
- **AI:** Groq (llama-3.3-70b-versatile)
- **Database:** MySQL
